Purpose

This policy helps protect the facility's computers, network and research information from security threats and unauthorised access.

Security Rules

  • Employees must use their own login accounts.
  • Passwords must not be shared.
  • Multi-factor authentication must be used where required.
  • Computers must be locked when unattended.
  • Only authorised employees may access sensitive information.
  • Administrator access must be limited to authorised IT staff.
  • Software installations require IT approval.
  • Antivirus protection must remain enabled.
  • Operating systems must be updated regularly.
  • Unauthorised devices must not connect to the network.
  • Research data must not be stored in personal cloud accounts.
  • Removable storage devices require permission.
  • Unused network ports must be disabled where appropriate.
  • Network management interfaces must be restricted.
  • Firewall and VLAN access rules must be followed.
  • Important information must be backed up securely.
  • Suspicious emails must be reported.
  • Lost or stolen devices must be reported immediately.
  • Security incidents must be reported to the Cybersecurity Officer.
  • User access must be removed when employment ends.

Responsibility

All employees must follow this policy. The Cybersecurity Officer and IT Manager are responsible for monitoring compliance.
